Saved run records

class bpupga.RunLog(attempt_dir, _record, _failure=None)[source]

Read an existing attempt’s current result.json or started.json snapshot.

Does not scan matrices, rerun inference, write, watch or update a campaign. Failure/running scores are None, never successful zeroes.

summary()[source]

RunLog.open accepts an existing per-task attempt directory and reads its result.json or started.json. It creates a read-only snapshot and loads no saved score matrices. Reopen it to refresh a running attempt.

Only successful native reports expose native_metrics. Failed, unfinished or absent reports remain None. Missing records raise FileNotFoundError; malformed records raise ValueError.

See Saved runs and resources for status interpretation and browser-local JSON inspection.
