Custom adapter registration

bpupga.register_algorithm(name, factory)[source]

Register a new name without replacing a built-in or existing adapter.

factory(parameters=…, seed=…, device=…, dataset_family=…) returns an object with fit(graph1, graph2) -> AlignmentResult. The factory never receives a Dataset. Custom code must preserve the unsupervised contract.

The factory accepts parameters, seed, device and dataset_family as keyword arguments and returns an adapter with fit(graph1, graph2). Its output must be bpupga.AlignmentResult.

Names cannot replace a built-in or an existing registration. Duplicate names or incompatible factories raise ValueError or TypeError. Registration is local to the Python process.

See Custom algorithms for a complete graph-only adapter and optional ranking representations.
