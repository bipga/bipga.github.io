The record contains root, name, the two local-ID topology graphs, ground_truth, the g1_old_to_new / g2_old_to_new maps, their inverse maps, and metadata. Original identifiers can be recovered with data.pairs_to_original(result.predicted_pairs).

AlignmentResult

class bpupga.AlignmentResult(method: 'str', predicted_pairs: 'List[Tuple[int, int]]', runtime_sec: 'float', peak_memory_mb: 'Optional[float]' = None, score_matrix: 'Optional[np.ndarray]' = None, cost_matrix: 'Optional[np.ndarray]' = None, source_embeddings: 'Optional[np.ndarray]' = None, target_embeddings: 'Optional[np.ndarray]' = None, ranking_candidates: 'Optional[List[Tuple[int, int, float]]]' = None, larger_is_better: 'Optional[bool]' = None, partial_decoder_data: 'Optional[Dict[str, np.ndarray]]' = None, metadata: 'Dict[str, object]' = <factory>, stage_score_matrices: 'Dict[str, np.ndarray]' = <factory>, stage_diagnostics_metadata: 'Dict[str, Dict[str, object]]' = <factory>)[source]
validate_shapes(num_source_nodes, num_target_nodes)[source]

method, predicted_pairs and runtime_sec identify the native output. Optional fields include score_matrix, cost_matrix, source_embeddings, target_embeddings and ranking_candidates. larger_is_better describes continuous-score direction and metadata retains method-specific information.

Matrix dimensions must match the two graph orders. Sparse candidates use local source and target IDs with a finite score; missing candidate pairs are not fabricated. See Custom algorithms for a custom-adapter example.
