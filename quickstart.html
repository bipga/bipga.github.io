Quick start

First run: a self-contained example

After Installation and downloads, run this example to check graph loading, custom adapter registration and evaluation. It creates its own temporary inputs and does not invoke a built-in model. Its degree matcher demonstrates the API contract rather than a benchmark result.

Download toy_example.py

python toy_example.py
View the complete toy example
"""Run a small local API example without invoking a built-in model.

Install the BiPGA package before running this example.
This degree-based adapter illustrates the contract; it is not a baseline claim.
"""
import json
import tempfile
from pathlib import Path

import bpupga as bp


class DegreeAdapter:
    def fit(self, graph1, graph2):
        source = sorted(graph1, key=lambda u: (-graph1.degree(u), u))
        target = sorted(graph2, key=lambda v: (-graph2.degree(v), v))
        return bp.AlignmentResult(
            method="degree_example",
            predicted_pairs=list(zip(source, target)),
            runtime_sec=0.0,
        )


def factory(*, parameters, seed, device, dataset_family):
    return DegreeAdapter()


def main():
    bp.register_algorithm("degree_example", factory)
    with tempfile.TemporaryDirectory(prefix="bpupga-demo-") as directory:
        root = Path(directory)
        (root / "G1.edgelist").write_text("10 11\n11 12\n")
        (root / "G2.edgelist").write_text("20 21\n21 22\n")
        (root / "G1.nodes").write_text("10\n11\n12\n13\n")
        (root / "G2.nodes").write_text("20\n21\n22\n23\n")
        (root / "Alignment.json").write_text(
            json.dumps({"10": 20, "11": 21, "12": 22}))
        (root / "metadata.json").write_text(json.dumps({
            "purpose": "API toy example",
            "ground_truth_complete": True,
        }))
        data = bp.Dataset.load(root)
        method = bp.Algorithm("degree_example", seed=2026)
        result = method.align(data.graph1, data.graph2)
        report = bp.evaluate(result, data)
        print("Pair metrics:", report["pair"])
        print("Validity:", report["validity"])
        print("Original IDs:", data.pairs_to_original(result.predicted_pairs))
        print("Ranking availability:", report["ranking_policy"])


if __name__ == "__main__":
    main()

Run a built-in method

Download the supplied graph inputs once, then run a registered method:

bipga download --output paper

import bpupga as bp

data = bp.Dataset.load(
    "paper/datasets/fbtw/base")
method = bp.Algorithm(
    "grampa", parameters={"eta": 1.0}, seed=2026, device="cpu")
result = method.align(data.graph1, data.graph2)
metrics = bp.evaluate(result, data, ks=(1, 5, 10))
print(metrics["pair"])

The algorithm receives data.graph1 and data.graph2. Evaluation receives the reference-bearing dataset only after alignment returns.

Inspect the output


metrics["pair"] reports native pair precision, recall and F1.
metrics["validity"] reports correspondence feasibility.
metrics["ranking_policy"] explains which same-fit representation supplies
the rankings, or why ranking metrics are unavailable.


For the command-line workflow, continue with Command-line interface. For input formats and
evaluation definitions, see Datasets and construction and Evaluation and metrics.
