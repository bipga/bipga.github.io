Reproduce the results

Use Python 3.10 to extract the archive and reproduce the supplied diagnostic results:

Terminal
python -m zipfile -e BiPGA_artifacts.zip .
cd bipga
python -m pip install -r requirements-analysis.txt
python scripts/reproduce_diagnostics.py --output diagnostics_recomputed

The included README.md covers installation, model execution and plotting. DATA_INDEX.md lists the data for each figure and table.
