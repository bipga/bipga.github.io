Supplementary Material

Code, data and experimental results accompanying the ICDE 2027 submission.

Complete artifact

Download BiPGA_artifacts.tar.xz

The archive contains method implementations, graph inputs, experiment configurations, numerical observations, paper figures and tables, and reproduction scripts for all twelve methods.

Reproduce the results

Use Python 3.10 to extract the archive and recompute the supplied numerical results for Figures 5–9 and Tables II, IV–VI:

tar -xf BiPGA_artifacts.tar.xz
cd bipga
python -m pip install -r requirements-analysis.txt
python scripts/reproduce_results.py --output reproduced

This command uses the supplied observations. The complete reproduction guide covers graph inputs, model fitting, evaluation, seed aggregation, expected outputs and plotting. The same guide is included as REPRODUCE.md in the archive.
