# BPUPGA documentation website

This repository publishes the account-level GitHub Pages website for **bipga**.

Expected address after enabling Pages: https://bipga.github.io/

## Publish once

1. Create a Public repository named exactly `bipga.github.io` under account `bipga`.
2. Upload these files to its `main` branch, with `index.html` at the repository root.
3. In Settings → Pages, choose Deploy from a branch, main, and /(root), then Save.
4. Leave Custom domain empty. GitHub supplies the `bipga.github.io` hostname and HTTPS.

The existing project and repository documentation remain at https://github.com/bipga/bpupga-api.
The earlier project website can remain available at https://bipga.github.io/bpupga-api/.
No domain registration, purchase, or DNS changes are required for this GitHub-provided hostname.
