Installation
============

Requirements
------------

Use Python 3.10 or newer and the complete research checkout. The interface
package lives in ``baseline_exdit_261029/api/bpupga`` and delegates to the
adjacent method implementations and graph-construction code.

NetworkX and NumPy support graph loading. Evaluation additionally uses
scikit-learn; diagnostics uses SciPy and the sibling diagnostic implementation.
Built-in methods need their model dependencies and any bundled weights.

Use the research checkout
-------------------------

From the repository root, activate the project's model environment and add the
API directory to Python's import path:

.. code-block:: bash

   export PYTHONPATH="$PWD/baseline_exdit_261029/api${PYTHONPATH:+:$PYTHONPATH}"
   python -c "import bpupga; print(bpupga.__file__)"

An editable installation is also supported in that environment:

.. code-block:: bash

   python -m pip install --no-deps --no-build-isolation -e baseline_exdit_261029/api

The installed distribution is named ``bpupga-local`` and the import is
``bpupga``. It is a repository-bound interface rather than a PyPI release;
retain the surrounding implementations and use their existing dependencies.

.. note::

   The public documentation repository contains source snapshots and examples.
   Running all built-in methods requires the complete research checkout.
   The `paper artifact <https://bipga.github.io/supplementary/>`_ has its own
   complete installation and reproduction workflow.

Verify the interface
--------------------

Download the `toy example <downloads/toy_example.py>`_, then run it from an
environment with the interface available:

.. code-block:: bash

   python toy_example.py

The example creates temporary graph inputs, registers a small custom adapter
and evaluates its output. It requires no benchmark data, model fit or GPU.

Working directories
-------------------

Examples on this site use paths relative to the research repository root.
From ``baseline_exdit_261029/``, set ``PYTHONPATH=api`` instead. Keep output
directories new so that construction and experiment records remain intact.

See :doc:`faq` for import collisions, missing dependencies and device errors.
