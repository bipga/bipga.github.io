Installation and downloads
==========================

BiPGA includes all twelve methods, their required weights, graph construction,
evaluation, diagnostics and plotting in one standalone Python distribution.
Use Linux and Python 3.10 for the complete method environment.

Python package
--------------

`Download the wheel <downloads/bipga-0.1.0-py3-none-any.whl>`_ ·
`Download the source distribution <downloads/bipga-0.1.0.tar.gz>`_

Install the CPU method dependencies and the wheel directly:

.. code-block:: bash

   python3.10 -m pip install torch==2.10.0 --index-url https://download.pytorch.org/whl/cpu
   python3.10 -m pip install "bipga[all] @ https://bipga.github.io/downloads/bipga-0.1.0-py3-none-any.whl"
   bipga doctor --all
   bipga methods

Import the API with ``import bpupga as bp`` or ``import bipga as bp``.
Both names expose the same interface. The package includes its runtime sources
and weights and runs independently of a research checkout.

Complete runtime
----------------

`Download the complete runtime <downloads/BiPGA_runtime.tar.xz>`_

This archive includes the wheel, installation and launch scripts, GPU Dockerfile,
and the complete paper code, graph inputs and recorded results. The wheel
contains the Python method sources and weights. Initial dependency installation
uses the Internet.

.. code-block:: bash

   tar -xf BiPGA_runtime.tar.xz
   cd bipga-runtime
   bash install.sh --cpu
   bash bipga.sh doctor --all
   bash bipga.sh demo --method all --device cpu --output demo_cpu

The installer creates a local ``.venv/`` and extracts the bundled paper artifact
into ``paper/``. It does not run an experiment. Use ``--python PATH`` to select
a Python 3.10 interpreter. ``bash bipga.sh`` launches the installed commands.

GPU container
-------------

The public image includes the installed package, pinned method dependencies and
CUDA development tools. Pull and run it directly:

.. code-block:: bash

   docker pull ghcr.io/bipga/bipga:0.1.0
   docker run --rm --gpus all ghcr.io/bipga/bipga:0.1.0 doctor --all --require-gpu
   docker run --rm --gpus all -v "$PWD:/work" ghcr.io/bipga/bipga:0.1.0 \
       demo --method all --device cuda:0 --output /work/demo_gpu

The complete runtime also includes a `Dockerfile <downloads/Dockerfile>`_. To
build the image locally, run this command in its extracted directory:

.. code-block:: bash

   docker build -f docker/Dockerfile -t bipga-gpu .

The host needs a compatible NVIDIA driver, Docker and NVIDIA Container Toolkit.
The image supplies the CUDA compiler. Select devices through Docker's ``--gpus``
option and use the corresponding visible device, such as ``cuda:0``.

For a native CUDA environment, run ``bash install.sh --gpu`` in the complete
runtime and provide ``nvcc`` through ``PATH`` or ``BPUPGA_NVCC``.

Verify and reproduce
--------------------

``bipga demo`` uses small generated graph pairs and reduced optimization budgets
for installation checks. ``--defaults`` selects adapter defaults. These examples
are distinct from the paper's recorded experiment configurations.

.. code-block:: bash

   bipga reproduce --artifact paper --output reproduced
   bipga plot --data-root reproduced/data --figure 9 --output figure09

Replaying the supplied observations runs on a CPU and does not fit models.
For full model fitting and the paper's execution profiles, follow the
:doc:`reproduction guide <supplementary/reproduce/index>`.

Continue with :doc:`quickstart` for the Python API and :doc:`cli` for commands.
