Quick start
===========

First run: a self-contained example
-----------------------------------

After :doc:`installation`, run this example to check graph loading, custom
adapter registration and evaluation. It creates its own temporary inputs and
does not invoke a built-in model. Its degree matcher demonstrates the API
contract rather than a benchmark result.

`Download toy_example.py <downloads/toy_example.py>`_

.. code-block:: bash

   python toy_example.py

Inspect the output
------------------

``metrics["pair"]`` reports native pair precision, recall and F1.
``metrics["validity"]`` reports correspondence feasibility.
``metrics["ranking_policy"]`` explains which same-fit representation supplies
the rankings, or why ranking metrics are unavailable.

For the command-line workflow, continue with :doc:`cli`. For input formats and
evaluation definitions, see :doc:`datasets` and :doc:`evaluation`.
