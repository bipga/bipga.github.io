Command-line interface

The bipga command runs the installed package. python -m bpupga and python -m bipga expose the same commands.

Available commands

Command

Purpose

methods

List all twelve method identifiers and supported devices.

doctor

Check dependencies, bundled files and CUDA availability.

demo

Run a small generated graph example for one or all methods.

run

Align a supplied graph pair and save native outputs and metrics.

construct

Construct a bilateral partial pair from supplied graph files.

evaluate

Evaluate or diagnose saved same-fit outputs.

download

Download and extract the complete paper artifact.

reproduce

Recompute the paper’s numerical summaries from recorded observations.

plot

Render Figures 5–9 from supplied or recomputed tables.

paper

Run a recorded paper configuration with its execution profile.

Use bipga COMMAND --help for the options of a command.

Check the installation

bipga doctor --all
bipga methods
bipga demo --method all --device cpu --output demo_cpu

For a CUDA environment, add --require-gpu to doctor and select a visible device such as --device cuda:0 for a fit. The small installation demo uses reduced budgets; add --defaults to use adapter defaults.

Align a graph pair

--data identifies a directory containing G1.edgelist, G2.edgelist, optional explicit node lists and an evaluation reference Alignment.json.

bipga run --data graph_pair --method grampa --parameters '{"eta":1.0}' \
    --device cpu --seed 2026 --output results --diagnostics
bipga evaluate --data graph_pair --fit results/fit --output metrics.json

The inference subprocess receives topology, method parameters, seed and device. Reference correspondences stay in the parent and are used after inference. Outputs include native pairs, same-fit scores or embeddings, fit metadata, metrics, logs and a status record. RunLog.open("results") reads the record. Existing output directories are never overwritten. Failed fits retain their status and log; missing scores are never reported as valid zeros.

Construct graph inputs

bipga construct --data raw_pair --rho-source 0.8 --rho-target 0.8 \
    --seed 2026 --output partial_pair

Paper reproduction

Download the artifact once, or use the paper/ directory included by the complete runtime installer:

bipga download --output paper
bipga reproduce --artifact paper --output reproduced
bipga plot --data-root reproduced/data --figure 5 --output figure05.pdf
bipga plot --data-root reproduced/data --figure 9 --output figure09

These commands replay observations and render outputs without fitting models. To select a recorded model configuration, pass arguments after -- to the paper runner:

bipga paper --artifact paper -- --list --dataset fbtw --method alpine
bipga paper --artifact paper -- --run-id RUN_ID --output fresh_fit --dry-run
bipga paper --artifact paper -- --run-id RUN_ID --device cuda:0 --output fresh_fit

Replace RUN_ID with one listed configuration. The final command fits a model; full experiment execution requires the documented GPU environment. See the complete reproduction guide for grouping fresh fits, diagnostics, seed aggregation and expected outputs.
