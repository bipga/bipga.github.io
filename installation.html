Installation

Requirements

Use Python 3.10 or newer and the complete research checkout. The interface package lives in baseline/api/bpupga and delegates to the adjacent method implementations and graph-construction code.

NetworkX and NumPy support graph loading. Evaluation additionally uses scikit-learn; diagnostics uses SciPy and the sibling diagnostic implementation. Built-in methods need their model dependencies and any bundled weights.

Use the research checkout

From the repository root, activate the project’s model environment and add the API directory to Python’s import path:

export PYTHONPATH="$PWD/baseline/api${PYTHONPATH:+:$PYTHONPATH}"
python -c "import bpupga; print(bpupga.__file__)"

An editable installation is also supported in that environment:

python -m pip install --no-deps --no-build-isolation -e baseline/api

The installed distribution is named bpupga-local and the import is bpupga. It is a repository-bound interface rather than a PyPI release; retain the surrounding implementations and use their existing dependencies.

Note

The public documentation repository contains source snapshots and examples. Running all built-in methods requires the complete research checkout. The paper artifact has its own complete installation and reproduction workflow.

Verify the interface

Download the toy example, then run it from an environment with the interface available:

python toy_example.py

The example creates temporary graph inputs, registers a small custom adapter and evaluates its output. It requires no benchmark data, model fit or GPU.

Working directories

Examples use a checkout folder named baseline/ with prepared graphs in baseline/data/. Paths are relative to its parent directory. From baseline/, set PYTHONPATH=api instead. Keep output directories new so that construction and experiment records remain intact.

See Troubleshooting and FAQ for import collisions, missing dependencies and device errors.
